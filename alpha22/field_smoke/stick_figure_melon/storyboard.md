# 原创试片：会挑下班的瓜

| 时间 | 可见动作 | 节奏目的 |
|---|---|---|
| 0–1.0s | 顾客入画，瓜摊建立 | 清楚摆位 |
| 1.0–2.2s | 指瓜、提问 | 预备动作与信息 |
| 2.2–3.2s | 摊主自信回应 | 建立错误预期 |
| 3.2–4.0s | 敲击与瓜的挤压 | 动作重音 |
| 4.0–4.9s | 瓜睁眼长腿，双方定格 | 喜剧停顿 |
| 4.9–6.3s | 瓜加速逃跑 | 拉伸、拖影、速度线 |
| 6.3–8.0s | 空桌与画外反转气泡 | 笑点落地 |

原创边界：借鉴“买瓜情境触发反转”的通用喜剧结构，以及传统动画的节奏原则；不复刻《征服》、影视飓风仿拍或任何火柴人视频的具体人物、台词、镜头、声音和画面。
