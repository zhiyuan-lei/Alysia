# 买瓜：保熟吗？——第二版试片分镜

| 时间 | 剧情/动作 | 表情与节奏 |
|---|---|---|
| 0–1.3s | 顾客从右侧小跑进瓜摊 | 围巾、四肢跟随摆动，摊主眯眼打量 |
| 1.3–2.5s | 顾客指瓜询价 | 顾客好奇，摊主抬手指价格牌 |
| 2.5–3.5s | 摊主报价格 | 摊主得意，牌子轻晃 |
| 3.5–5.1s | 顾客俯身、敲瓜、问保熟 | 眉眼收窄，敲击瞬间用单帧重音 |
| 5.1–6.2s | 摊主拍胸脯保证 | 大幅点头，围裙延迟摆动 |
| 6.2–7.4s | 摊主用小瓜刀切开一角 | 预备、快速切割、瓜瓣弹起，画面只表现水果切面 |
| 7.4–8.7s | 淡粉瓜瓤暴露；顾客指出问题 | 双方瞪眼，顾客从惊讶变质疑 |
| 8.7–10.1s | 摊主恼羞回应，双方前倾 | 眉毛压低、汗滴、怒目和速度线；不打斗 |
| 10.1–12s | 两人僵持；价签摇晃、瓜籽掉下 | 长停顿作为笑点；封镜 |

与首版区别：原版“西瓜长腿逃跑”是原创反转，不符合用户现在明确要求的复刻剧情；第二版替换为保熟质疑和切瓜后的对峙。保留低绘制帧数，但增加场景细节、手势、走路、俯身、点头、切瓜、后仰/前倾及多种脸部状态。独立试片，未接入 Alysia。
